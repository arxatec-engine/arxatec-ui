# Shipped — 2026 W41

## SVG transparente de Apple — 2026-10-09

> **Branch:** `main` · **PR:** #20 cerrado por petición del usuario · **Published:** pendiente

**Intent.** Compartir el icono de Apple con la plataforma y eliminar el fondo
negro incrustado en la imagen usada por el selector de acceso.

**What changed.** `AppleIsotype` conserva el path del logo como un SVG inline
transparente, con un viewBox cuadrado ajustado, `fill=currentColor` y props SVG.
Se exporta desde el barrel público de iconos y se muestra en `Marcas`,
`AppleEnTemas` y la guía de estilos. README y guía operativa documentan el
contrato. La versión preparada es `0.1.70`; la plataforma consume el icono
mediante un parche limitado de pnpm sobre su `arxatec-ui@0.1.68` instalado.

**How it was verified.** Pasan `pnpm exec tsc -b tsconfig.build.json`, ESLint de
los archivos modificados, `npm run build:lib`, `npm run build-storybook`,
Prettier del alcance y `git diff --check`. Se revisan las exportaciones JS/TS y
el SVG sin rectángulo de fondo. La plataforma pasa tipos, lint y builds web y
Electron con el parche y conserva los pins y peers del lockfile.

**Publication steps.** Paso 1: se creó la branch propia y el borrador de PR #20;
el usuario pidió después cerrar el PR y llevar el cambio directamente a `main`.
Se integra el icono en `main` siguiendo esa instrucción explícita. Pasos 2 y 3:
publicación desde main limpio y actualización de consumidores pendientes del
owner y de la antigüedad de siete días. El parche permite el uso actual del
icono en la plataforma sin una nueva versión de registro.

**What is still open.** Publicación del paquete. Al consumir una release
que incluya el icono, se retira el parche temporal de la plataforma.
