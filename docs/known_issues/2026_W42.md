by the security fix. The registry's current advisory database also reports other
issues in the existing dependency graph. No automated PR audit gate exists.

`pnpm audit --prod --json`.

  41 high, 3 critical). These are advisory findings across versions, not 61

  It does not represent the current manifest; see D-2 in `2026_W32.md`.
